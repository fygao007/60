# PC 框架布局生成规范

来源：MasterGo《📌【PC】框架布局》

## 使用目的

后续根据业务需求生成前端页面时，默认遵循本规范组织页面框架。业务需求只描述页面内容、字段、操作和状态；页面外壳、导航、内容区布局按本规范自动生成。

> 当前项目已进一步沉淀出可执行的三层应用外壳规范，见 `specs/pc-app-shell-spec.md`。生成新 PC 页面时优先读取该文件，再读取本文档。

## 适用范围

- Web 端 MIS 类后台页面
- 信息管理类多应用 / 单应用
- 列表页、卡片页、表单页、空状态引导页、反馈结果页
- 左右分栏、泳道、看板类内容区布局

## 框架类型

### B 类：信息管理端

优先用于管理后台、教务/人事/科研等业务系统。

- 多应用：适合多个子系统并列入口，例如专业研究方向管理、考试科目采集、招生计划管理等。
- 单应用：适合单一业务系统售卖或单系统部署。

### C 类：终端用户端

用于面向普通用户的工作台、服务大厅、消息、待办、日程等场景。

## 默认页面框架

生成 PC 后台页面时默认采用：

1. 左侧主系统导航。
2. 导航区，承载二级导航并支持展开/收起。
3. 右侧操作区，承载顶部标签、业务内容和底部操作。
4. 内容区背景。
5. 表格/表单/卡片等业务内容。

## 左侧导航规范

### 结构

- 左侧为主系统导航，支持多应用与单应用。
- 菜单可包含一级或二级结构。
- 支持展开/收起状态。
- 支持选中、未选中、悬浮状态。

### 状态

- 未选中-未悬浮
- 未选中-悬浮
- 选中-未悬浮
- 选中-悬浮

### 颜色

- 选中菜单颜色使用 `baseColor2`。
- 内容区背景使用规则：`backgroundColor(baseColor, H,S=50, L=97)`。
- 导航底色可绑定深色渐变变量。

## 顶部导航规范

- 顶部导航用于承载当前打开的应用/页面 Tab。
- Tab 支持关闭。
- 当前页面 Tab 高亮。
- 右侧可放全局操作：刷新、全屏、用户设置等。

## 内容区规范

### 背景

- 内容区背景不使用纯白，使用低饱和浅色背景。
- 默认背景可近似为 `#F5F7FB`。

### 内容容器

- 页面内容通常放入白色卡片容器。
- 卡片圆角建议 8-10px。
- 卡片边框使用浅边线。
- 卡片间距建议 12-16px。

### 常见内容页

- 列表页：筛选区 + 工具栏 + 表格 + 分页。
- 卡片页：筛选区 + 卡片列表 + 分页/加载更多。
- 表单页：标题区 + 分组表单 + 底部操作区。
- 空状态引导页：插画 + 文案 + 主按钮。
- 反馈结果页：结果图标 + 结果标题 + 说明 + 操作按钮。

## 列表页默认布局

后续若需求包含“列表、查询、分页、操作列”，默认生成如下结构：

1. 页面标题区
   - 标题
   - 说明文字，可选
   - 右侧主操作按钮，可选

2. 查询筛选区
   - 输入框 / 选择器 / 日期等查询条件
   - 查询、重置按钮
   - 更多筛选展开按钮，可选

3. 列表工具栏
   - 左侧：列表标题、总数、已选数量
   - 右侧：新增、导入、导出、批量操作等按钮

4. 数据表格
   - 首列可为复选框或操作列
   - 中间为业务字段
   - 右侧为行内操作
   - 状态字段使用 Tag
   - 重要限制用黄色提示标签

5. 分页区
   - 总记录数
   - 总页数
   - 上一页/下一页
   - 跳页
   - 条数切换

## 组件使用优先级

生成 React 页面时优先使用本地组件库：

```js
import { DSButton, DSButtonGroup, DSCrudTemplate } from '@wisedu/design-system'
```

如组件库没有对应组件，允许在页面级 CSS 中临时实现视觉样式，但应保持与设计系统 token 一致。

## 输出约定

根据用户需求生成页面时，默认提供两种输出之一：

- React 页面：用于接入业务项目。
- 独立 HTML：用于快速视觉预览。

若用户未指定，先生成独立 HTML 预览；确认后再转 React 页面。

## 用户给需求时建议格式

```text
页面名称：
页面类型：列表页 / 表单页 / 详情页 / 审核页 / 导入向导 / 看板页
查询条件：
表格字段：
顶部操作：
行内操作：
批量操作：
特殊规则：
需要展示状态：默认 / 空态 / 弹窗 / 抽屉 / 已选中 / 错误提示
输出形式：HTML / React
```
