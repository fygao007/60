# 审核类页面框架规范

来源：MasterGo《📌【PC】场景模板》审核模板链接，以及已提供的审核列表截图。

## 适用场景

- 教材审核、专业目录审核、申报审核、任务审核等“待办审核 + 列表处理”页面。
- 页面核心任务是按状态筛选记录，并在行内完成通过、不通过、退回、详情等审核动作。

## 页面结构

1. 使用 PC 框架布局：左侧系统导航、顶部多页签、右上框架图标操作、内容区。
2. 内容区顶部放业务状态页签，常见为：`待审核`、`已审核`、`全部`。
3. `待审核` 等待办状态支持红色数量角标。
4. 状态页签下方是查询筛选区，字段按业务配置，默认使用单行横向布局。
5. 列表区域包含工具栏、表格、分页。
6. 审核类表格的行内操作列固定在最右侧，操作包括：`通过`、`不通过`、`退回`、`详情`。

## 组件落地

- `DSAuditTemplate`：审核类页面组合模板。
- `DSAuditStatusTabs`：待审核 / 已审核 / 全部等审核状态页签，支持待办数量角标。
- `DSAuditToolbar`：审核列表工具栏，承载总数、已选数量、导出、批量通过、批量退回。
- `DSAuditActions`：表格行内审核操作组，默认包括通过、不通过、退回、详情。
- `DSAuditOpinionModal`：通过、不通过、退回等审核意见弹窗；不通过和退回默认要求填写意见。
- `DSAuditDetailDrawer`：审核详情抽屉，展示提交信息、状态、业务字段和扩展内容。
- `DSAppShell`：承载左侧导航、顶部页签、框架操作图标。
- `DSFilterBar`：承载审核查询条件。
- `DSDataTable`：承载审核列表、行内操作、批量操作。
- `DSPagination`：承载审核列表分页。
- `DSIconButton`：承载刷新、全屏等框架图标按钮。

## 生成规则

- 默认字号使用 `14px`，辅助统计使用 `13px`，角标使用 `12px`。
- 状态页签选中态使用主色下划线，不使用大面积色块。
- 待办数量角标使用危险色背景，避免和主按钮混淆。
- 表格行高使用 `--ds-table-row-height`，表头使用浅灰背景。
- 审核表格操作列放在最后一列；只有明确复用旧 CRUD 模板时，才允许显式设置为左侧。
- 审核操作保持文本按钮形态，危险动作仅在确认弹窗或失败语义中使用红色。
- 批量通过、批量退回在未选择数据时默认禁用。
- 点击通过 / 不通过 / 退回应弹出审核意见弹窗；点击详情应打开详情抽屉。
