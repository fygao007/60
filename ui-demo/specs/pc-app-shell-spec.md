# PC 应用框架外壳规范

本文档沉淀当前 `primary-nav.html` 已实现的框架结构，用于后续生成 PC 管理端页面。

## 三层结构

框架分为三层，层级从低到高：

1. **一级导航层**
   - 固定在最左侧。
   - 宽度视觉体系为 `80px`，内容主体按 `64px + 8px * 2` 排布。
   - 负责 Logo、系统名、搜索、一级业务入口、底部工具、头像和管理员入口。

2. **导航区**
   - 从左侧 `64px` 开始覆盖在一级导航上方。
   - 背景为浅色渐变。
   - 展开时包含 `180px` 二级导航栏。
   - 收起时隐藏二级导航栏，只保留右侧操作区。

3. **操作区**
   - 覆盖在导航区右侧。
   - 展开二级导航时，占据二级导航右侧剩余空间。
   - 收起二级导航时，自动扩展到一级导航右侧。
   - 包含顶部标签、内容区、底部分页/操作栏。

## 一级导航

文件结构参考：

- `.primary-nav`：一级导航根容器。
- `.primary-nav-head`：Logo、系统名、收起态展开按钮、搜索、首页。
- `.primary-nav-list`：一级业务菜单。
- `.primary-tools`：底部工具入口。
- `.primary-user`：管理员区域。

一级菜单必须支持按业务配置替换文字和图标：

```html
<a class="primary-nav-item" href="#" data-module="doctor">
  <span class="primary-nav-icon">
    <span class="wise-icon" data-wise-icon="doctor"></span>
  </span>
  <span class="primary-label">博士</span>
</a>
```

## 二级导航

二级导航位于 `.navigation-menu`，宽度 `180px`。

展开态：

- 顶部显示收起按钮 `indent-decrease.png`。
- 中部显示当前一级模块对应的二级菜单。
- 带子菜单的父级行支持展开/收起，展开时右侧箭头向上，收起时右侧箭头向下。
- 父级行只控制子菜单显示，不刷新右侧操作区、不新增顶部页签。
- 父级行不参与选中态，不展示选中背景。
- 子级菜单项才作为功能入口，点击后刷新右侧操作区并联动顶部页签。
- 二级导航层级为“一级菜单分组 -> 子集菜单分组/末级菜单 -> 末级菜单”。
- 子集菜单分组必须归属在某个一级菜单分组内部，例如“通用信息管理”“超管配置”属于“专业目录”分组内部。
- 菜单分类只用于切分复杂菜单；分类不点击、不展开、不选中，分类下方直接展示末级功能项。
- 页面必须位于末级菜单项，不能挂在可展开的分组父级上。
- 底部显示流程参数入口。

收起态：

- `.navigation-menu` 隐藏。
- `.primary-collapse-toggle` 在一级导航内部显示，使用 `indent-increase.png`。
- 搜索、首页、一级菜单按文档流顺势下移。

## 操作区

操作区位于 `.operation-area`。

结构：

- `.operation-tabs-bar`：顶部标签行。
- `.operation-tabs`：顶部功能页签，一行横向排列，超出宽度时横向滚动。
- `.operation-body`：白色内容区域。
- `.operation-header`：当前功能标题、元信息和操作按钮。
- `.operation-table-wrap`：业务表格/表单/卡片内容。
- `.operation-footer`：底部分页和提交按钮。

二级导航点击后必须刷新操作区：

1. 更新二级菜单选中态。
2. 如果顶部页签不存在该功能，则新增页签；如果已存在，则选中原页签。
3. 高亮当前标签。
4. 刷新当前页签对应的右侧内容标题和业务内容。

顶部页签状态规则：

1. 页签保持上次退出时的内容状态，单纯点击顶部页签只恢复状态，不刷新内容。
2. 点击左侧二级导航时，即便页签已存在，也要重新刷新该页签内容。
3. 每个页签右侧有关闭按钮；关闭后再次点击左侧导航，需要重新打开并刷新。
4. 所有页签固定在一行展示，禁止换行，超过可视宽度时使用横向滚动。
5. 所有页签末尾放置“关闭全部页签”按钮。
6. 页签行最右侧固定放置“刷新当前页签”和“全屏”按钮。

## 图标管理

图标统一维护在：

- `ui-demo/assets/icons/`
- `ui-demo/assets/icon-registry.js`

页面只通过名称引用：

```html
<span class="wise-icon" data-wise-icon="search"></span>
```

新增图标流程：

1. 将 SVG/PNG 放入 `ui-demo/assets/icons/`。
2. 在 `icon-registry.js` 的 `icons` 或 `inlineIcons` 中登记。
3. 页面使用 `data-wise-icon` 引用。

## 交互约定

- 点击一级导航：
  - 切换一级选中态。
  - 自动展开二级导航。
  - 渲染该模块二级菜单。

- 点击二级导航父级：
  - 展开/收起当前分组。
  - 不刷新右侧操作区。
  - 不新增顶部页签。

- 点击二级导航子级：
  - 切换二级选中态。
  - 刷新右侧操作区。
  - 记录到顶部最近操作标签。

- 点击顶部标签：
  - 恢复对应功能页面状态。
  - 不重新刷新内容。

- 点击顶部标签关闭：
  - 关闭当前页签并移除该页签状态。
  - 如果关闭的是当前页签，自动选中相邻页签；没有页签时操作区展示空状态。

- 点击关闭全部页签：
  - 清空全部页签和页签状态。
  - 后续点击左侧导航时重新打开对应功能。

- 点击刷新：
  - 只刷新当前激活页签内容。

- 点击收起/展开：
  - 展开态按钮位于二级导航顶部。
  - 收起态按钮位于 Logo/系统下方、搜索上方。

## 后续生成页面时的默认做法

新 PC 页面如果没有特别说明，默认基于此框架：

1. 复用一级导航和导航区。
2. 按业务配置一级/二级菜单。
3. 在操作区生成具体功能页面。
4. 保持顶部标签和二级菜单点击联动。
