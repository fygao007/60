该页面保存自教学 6.0 低代码系统：

- 地址来源：`/lowcode/#/jiaowu/eajcsjgl/campusPage`
- 页面名称：校区信息
- 技术栈特征：Vue、Element UI、VXE Table、Wisedu `res-*` 组件、`vab-*` 框架导航。
- 主题变量：`--wis-base-color-brand: #333fff`，浅品牌底色 `#f5f5ff` / `#fbfbff`，基础间距以 4/8/12/16/20/24px 为阶梯。

## 框架结构

页面采用固定管理端框架：

1. 左侧窄导航，主应用图标 + 模块入口。
2. 顶部虚拟页签行，页签承载已打开页面。
3. 内容区为白色工作区，外层背景为浅品牌色。
4. 右上角固定框架操作：刷新当前页签、进入全屏。

生成 HTML 预览时，顶部页签必须独立于内容区，不应把页签画在页面内容白卡片内部。

## 列表页结构

校区信息页面是标准单模型列表页：

- 页面页签：学校信息、校区信息、机构管理、年级管理等同级功能。
- 查询区：高级筛选入口 + 关键字输入 + 重置 + 查询。
- 工具栏：新增、删除、导入、导出、AI 智能导出、批量下载。
- 表格：VXE 风格表格，表头 40px，行高 46px，支持复选框、列宽、省略 tooltip、虚拟滚动。
- 行内操作：编辑、详情、删除，使用文字按钮。
- 空态：表格内显示 `table-empty.png` + `暂无数据`。
- 弹窗：Element Dialog 风格，底部右对齐取消/确定。

截图默认态细节：

- 内容区不显示独立页面标题，顶部虚拟页签已经表达当前位置。
- 查询区位于内容区首行：左侧为 `关键字` 标签 + 输入框，右侧依次为高级筛选图标按钮、`重置`、主按钮 `查询`。
- 操作按钮行位于查询区下方：左侧依次为 `新增`、`删除`、`导入`、`导出`；右侧为表格工具图标，例如全屏和列设置。
- 默认列表态不展示新增/编辑弹窗、删除确认、抽屉、统计卡或分页；这些只作为交互触发后的状态。
- 表格首列是拖拽手柄列，第二列是复选框列，不使用序号列。
- 表格行内操作在右侧，顺序为 `编辑`、`详情`、`删除`，三者均为品牌蓝文字按钮，删除在该系统默认态不单独标红。
- 启用状态是蓝色胶囊开关：文案 `启用` 在蓝色胶囊左侧，白色圆点在右侧；停用态为灰色胶囊。

## 字段模式

校区信息表格字段：

- 校区代码
- 校区名称
- 校区英文名称
- 所属行政区划
- 校区地址
- 是否默认校区
- 启用状态
- 操作

布尔/状态字段表现：

- `是否默认校区`：只读字典文本，是/否。
- `启用状态`：开关组件，左右文案为停用/启用。
- 操作按钮顺序：编辑、详情、删除。

## 组件映射

生成 React/HTML 预览时按以下方式贴近该低代码体系：

- 框架：`DSAppShell` 或页面级 `.shell + .nav + .top-tabs + .content`。
- 页签：32px 高，激活页签白底、圆角上沿、和内容区相连。
- 查询：关键字字段优先，复杂条件放入“高级筛选”入口。
- 按钮：主按钮为品牌蓝 `#333fff`，普通按钮白底浅边框，小尺寸 32px。
- 表格：表头浅灰，表体 46px 行高，首列拖拽、次列复选，操作列文字按钮，空态文案 `暂无数据`。
- 状态：启停用优先用胶囊 Switch；纯状态可用 `DSTag`。
- 弹窗：标题左对齐，关闭按钮右上角，底部按钮右对齐。

## 对当前组件库的影响

后续生成 60 系统页面时，优先复用已沉淀的组件，并补齐这些缺口：

- `DSSwitch`：启用/停用开关，支持左右文案。
- `DSAdvancedFilter`：高级筛选弹出层/条件区。
- `DSPageTabs`：框架顶部虚拟页签，统一页签行结构。
- `DSTableToolbar`：列表页工具栏，支持新增、删除、导入、导出、批量下载等标准动作。
- `DSConfirmDialog`：删除确认、错误提示等 Element 风格弹窗。
