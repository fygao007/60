日期选择器

基于 MasterGo 基础控件日期选择设计，覆盖输入框、日历面板、月份切换、今天、清除、禁用和错误状态。

基础状态

Default / Filled / Open / Disabled / Error

未选择

默认展示占位文字和日历图标。

已选择

选中后展示日期值，支持清除。

展开面板

面板展示当前月份，可选择日期或切换月份。

跨月选择

非本月日期弱化展示，点击后直接回填。

禁用

禁用态不可展开、不可选择。

错误

请选择业务日期。
