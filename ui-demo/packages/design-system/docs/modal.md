这份文档记录普通表单弹窗的结构、组件状态、尺寸与间距。

## 弹窗结构

1. 页面示例画布：`1440px × 820px`。
2. 遮罩：全屏黑色，透明度 `20%`。
3. 弹窗：居中显示，`600px × 560px`，白底、`8px` 圆角、`1px solid #EEEEF0`。
4. 标题栏：左侧标题，右侧关闭按钮。
5. 内容区：左右 `20px`，单列表单。
6. 底部操作栏：右对齐，“取消”次按钮和“确定”主按钮。

## 布局与行为规则

- 普通弹窗默认在视口水平、垂直居中。
- 表单使用单列布局，标签右对齐，控件占据剩余宽度。
- 内容超过弹窗可用高度时，内容区滚动，标题栏和底栏固定。
- 点击关闭、取消或遮罩关闭弹窗；按 `Escape` 关闭弹窗。
- 点击确定提交表单，提交反馈完成后关闭弹窗。
- 小屏时弹窗宽度使用视口减去 `24px`，字段改为标签在上、控件在下。

## 稿件注意事项

- D2C HTML 使用未定义的 `--space-4`，直接在浏览器打开会丢失原本的 `16px` 表单行间距；实现按设计变量含义保留 `16px`，不沿用该导出缺陷。
- 第六个字段的日期时间控件在 D2C 中被导出为固定 `450px` 宽，超过弹窗内容区实际剩余宽度。实现时按控件容器自适应宽度处理。
- 稿件最后连续展示两个日期区间字段，按原稿保留，不合并或删除。
